# Placeholder register

Lives at `.design-dna/placeholders.md` in the project. Every invented or
stand-in item on the page gets a row when it is created, not at review time.
The register MUST be empty (or every row owner-deferred) before any live
state; the [preship gate](preship-gate.md) enforces this. Visible labeling
in the rendered page is required in addition to a row here, never replaced
by it.

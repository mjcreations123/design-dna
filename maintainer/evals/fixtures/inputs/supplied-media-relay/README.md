# Supplied-media Relay Room fixture

## Why this fixture exists

This is a deterministic evaluation input for Design DNA's supplied-media path.
The three WebP files are already present, approved for this local evaluation,
and assigned different editorial jobs. A run must not depend on image
generation, stock search, an image CDN, or network access.

## Provenance and permission

The images were generated by OpenAI ImageGen on 2026-07-29 for this local
evaluation. The project owner authorized their use as synthetic concept media
for local Design DNA evaluation and demonstration. No real venue, event,
performance, person, or broadcast is documented, and no external photographer
credit, identity release, model release, property release, or separate asset
license is claimed. Consult the repository `LICENSE`; this fixture note does not
expand or replace it. Exact file hashes and the intentionally unrecorded model
version are documented in `media-provenance.json`.

## Approved premise

Relay Room is a fictional community radio studio with a small public listening
room. The concept supports live sessions, audience tapings, listening parties,
and local hosts. It is portfolio and evaluation material, not a real venue.

The following fictional sample program items are approved:

- Wednesday, 7:00 PM — Local Chorus: Open Session
- Friday, 8:00 PM — Neighborhood Listening Party
- Sunday, 4:00 PM — Host Workshop: Making a Field Interview

Those items are illustrative scenario data. They are not real bookings,
availability, broadcasts, or ticketed events. No address, capacity, price,
hours, history, staff biography, contact method, stream, booking system, review,
partner, sponsor, accessibility claim, or operating record has been supplied.

## Required public truth boundary

Include this sentence once in a proportionate footer or nearby note:

> Fictional concept for evaluation.

Do not repeat caveats through the page. Do not imply that the images document a
real place, person, performance, or broadcast.

## Supplied media and assigned jobs

The machine-readable record is `media-provenance.json`. Preserve that file and
all three image files byte-for-byte.

- `assets/atmosphere-listening-room.webp` — atmosphere and spatial orientation.
  Use it to establish what kind of room a visitor would enter.
- `assets/human-use-live-session.webp` — credible human use. Use it to show the
  social scale and live-session situation.
- `assets/material-detail-radio-booth.webp` — material and process detail. Use
  the booth, microphones, and console to support plain-language recording copy.

Crops and responsive `object-position` choices are allowed. Do not use one
image as a generic background everywhere, put all three into interchangeable
cards, or invent a different documentary caption.

## Evaluation request

Build a polished, current, dependency-free two-route concept:

- `index.html` should explain Relay Room and why someone would visit.
- `schedule.html` should help someone scan the three approved sample program
  items. Keep this route meaningfully text-led; it should not become another
  photo gallery.

Use comfortable typography and familiar visitor language. Do not add a
transmission-status panel, fake live stream, route or relay codes, technical
diagram, system metaphor, or decorative control. Every visible link and control
must work locally or be plain text.

The final result should use all three supplied images in their assigned roles
while retaining at least one substantial text-led region. Photography should
carry atmosphere, human use, and material detail; prose should carry schedule,
expectations, and decisions. Neither medium should merely repeat the other.

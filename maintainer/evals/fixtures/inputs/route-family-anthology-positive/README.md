# Alder Reach anthology — positive route-family fixture

This directory is a source-frozen fictional fixture. Alder Reach is not a real
place. Its ten already-built routes share one navigator and accessibility
foundation while their bodies follow the supplied material and reader jobs.
They are one non-normative test family, not a route menu or a required set of
differences for other projects.

Review or audit the fixture without editing any supplied file. Machine analysis
may verify route, link, silhouette, and capture contracts; it must not issue an
automatic aesthetic pass or an authorship score.

# Framer new-text font default

## Claim

Inter appears as a documented default in another major website-building ecosystem, strengthening the case for checking rather than automatically accepting it in greenfield identity work.

## Observation

Framer documents Standard Inter and Inter Display as default fonts for new text blocks while also supporting Google, Fontshare, open-source, and uploaded custom fonts.

## Scope and limitations

This describes Framer editor defaults, not every Framer Agent output, current AI model, exported site, or designer choice.

## Counterexamples

Inter can be excellent for dense interfaces, multilingual systems, existing brands, and performance-sensitive work.

## Positive action

Preserve explicit systems; for greenfield expressive work, compare real-copy alternatives and use Inter only when it wins for project-specific reasons.

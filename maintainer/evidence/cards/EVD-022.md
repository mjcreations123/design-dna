# Framer new-text font default

## Claim

This editor's documented starting choice is useful maintainer-only provenance
for ecosystem research. It does not justify checking, rejecting, or replacing
that typeface in an individual runtime project.

## Observation

Framer documents Standard Inter and Inter Display as default fonts for new text blocks while also supporting Google, Fontshare, open-source, and uploaded custom fonts.

## Scope and limitations

This describes Framer editor defaults, not every Framer Agent output, current AI model, exported site, or designer choice.

## Counterexamples

Inter can be excellent for dense interfaces, multilingual systems, existing brands, and performance-sensitive work.

## Positive action

Keep named-default research outside the installed selection workflow. Evaluate
every project from its real copy, inherited identity, composition, rights,
language coverage, delivery, and rendered behavior; do not add a penalty or
extra burden because a family appears in this evidence.

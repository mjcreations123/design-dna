# Anti-template guidance can become another template

## Claim

A shared negative recipe can converge into a replacement house style, so durable guidance must create project-specific decisions rather than rotate motifs.

## Observation

The community discussion contains both detailed anti-pattern lists and the counterpoint that a standard anti-slop prompt would itself become recognizable; several contributors instead emphasize context, design systems, iteration, and explicit constraints.

## Scope and limitations

This is anecdotal, self-selected discussion and does not measure output quality or prevalence.

## Counterexamples

Shared standards and familiar patterns are valuable when they protect access, clarity, safety, continuity, and task performance.

## Positive action

Use negative examples as diagnosis prompts while deriving content, hierarchy, system, and expression from each project's real evidence.

## Supports

`RISK-NOV-001`, `RISK-REPEAT-001`

## Validation

Compare unrelated skill outputs for a new repeated palette, type pairing, composition, or motion signature.

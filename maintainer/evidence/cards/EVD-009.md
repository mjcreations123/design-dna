# Reproducible Reddit-mined perception synthesis

## Claim

Current community perception clusters more strongly around generic sameness and untouched framework defaults than around several popular meme-level motifs.

## Observation

The published workflow reports 3.2 million scanned posts, 46,971 on-topic posts, and 3,033 comments from 125 canonical threads. Its leading concrete candidates are untouched shadcn/Tailwind defaults, purple, gradients, repeated animation, excessive rounding, dark-neon styling, emoji icons, generic fonts, and a centered hero plus three cards. It rejects mesh/aurora as a keyword artifact and finds bento weak.

## Scope and limitations

This is a reproducible community-text synthesis, not peer-reviewed visual research. Keyword construction, subreddit selection, sentiment, recency, and self-selection can bias results.

## Counterexamples

Every candidate can be correct when it fits the project and is implemented well.

## Positive action

Use the ranking to prioritize blinded output tests and code scans, not to create universal bans or authorship scores.

# Responsive interaction is more than viewport width

## Claim

Input modality and virtual-keyboard behavior cannot be inferred reliably from screen size.

## Observation

The guidance distinguishes fine, coarse, and absent pointers and explains how input types influence on-screen keyboards.

## Scope and limitations

This is interaction guidance, not a complete responsive or accessibility standard.

## Counterexamples

Some projects have a controlled device environment, but that constraint must be real.

## Positive action

Test touch, mouse, keyboard, hover/no-hover, virtual keyboards, and responsive layout separately.

## Supports

`RISK-RESP-001`

## Validation

Include input-mode and mobile-form fixtures in behavioral evaluations.

# Application security needs its own verification standard

## Claim

Front-end design, visual QA, and ordinary build checks do not establish
application security.

## Observation

OWASP ASVS provides a dedicated basis for testing web-application technical
security controls and a requirements set for secure development and procurement.

## Scope and limitations

ASVS is a security-verification framework, not a claim that every project needs
the same assurance level or that completing an unaudited checklist proves
security.

## Counterexamples

A static concept with no live data or action may have few applicable controls,
while a high-risk service can require additional standards and specialist work.

## Positive action

Identify security triggers, assign the appropriate assurance and specialist
scope, and keep security evidence separate from visual and functional review.

## Supports

`RISK-SEC-001`

## Validation

Record the applicable standard/version, scope, verifier, environment, evidence,
findings, remediation, retest, and exclusions.

# Geist as a v0 ecosystem default candidate

## Claim

Geist and Geist Mono merit attention as ecosystem defaults in v0/Vercel-generated projects, especially when a greenfield brief has no typographic reason for them.

## Observation

A Vercel community support reply says Geist can enter projects through v0's default design system; Vercel templates and v0 examples also commonly use the family.

## Scope and limitations

This is a support-thread observation, not stable product documentation or a representative output census. v0 behavior can change.

## Counterexamples

Geist is a capable, intentional Vercel brand family and can be correct for developer tools, existing Vercel systems, and readable product interfaces.

## Positive action

Treat Geist as a dated investigation prompt, not a ban; compare alternatives in greenfield expressive work and preserve legitimate ecosystem continuity.

## Validation

Test fresh v0-related outputs and retire this candidate if the current product no longer defaults to Geist.

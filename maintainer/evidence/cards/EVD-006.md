# Font delivery and layout stability

## Claim

Font choice is incomplete until delivery, fallback, and layout behavior are verified.

## Observation

The guidance explains how font loading and metric differences can delay text, create swaps, and contribute to layout shift.

## Scope and limitations

The best strategy depends on content, brand importance, network conditions, and supported browsers.

## Counterexamples

A carefully delivered web font can be stable and fast; a system stack can also be the best choice.

## Positive action

Load only required files, choose fallback and display behavior deliberately, and test slow, failed, and warm-cache rendering with real copy.

## Supports

`RISK-TYPE-002`

## Validation

Measure rendered text, fallback, glyph coverage, and layout shift rather than inspecting CSS alone.

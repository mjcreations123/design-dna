# Radical page expression still needs predictable repeated navigation

## Claim

A multi-page range study can vary its page bodies substantially while keeping
repeated navigation in the same relative order.

## Observation

WCAG 2.2 Understanding SC 3.2.3 explains that repeated navigation within a set
of pages should occur in the same relative order. The guidance explicitly
allows secondary navigation and page-specific structure, so consistent
orientation does not require identical body composition.

## Scope and limitations

The Understanding document is informative guidance for a Level AA success
criterion. It does not prescribe one masthead, visual position, component
library, or aesthetic, and it does not establish that all pages on a domain
belong to the same set of pages.

## Counterexamples

A checkout flow may intentionally omit the main site navigation and constitute
a different set of pages. A user-initiated personalization may also change the
order without violating the criterion.

## Positive action

Define the set of pages, preserve repeated navigation semantics and relative
order, provide a consistent skip path, and let the main content, secondary
navigation, density, and visual grammar follow each route's job.

## Supports

`RISK-IA-001`, `RISK-UX-001`

## Validation

Compare source order and rendered order for every repeated navigational
mechanism across all declared routes, then separately verify that route bodies
are differentiated by content and task rather than arbitrary restyling.

Public W3C guidance; retain a dated summary and review within 180 days or when
the Understanding document is materially revised.
